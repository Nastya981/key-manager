# Key Manager (TB1)

Дипломный проект: сервис управления ключами доступа.

## Стек технологий
- **FastAPI** — веб-фреймворк
- **MongoDB** (Motor) — асинхронная база данных
- **JWT** — авторизация
- **Encryption** — шифрование ключей
- **Docker / Docker-Compose** — контейнеризация

## Запуск
```bash
docker compose up --build
